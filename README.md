# Нейросеть, которая пишет за тебя в Telegram

Дообучаем языковую модель на своих переписках, чтобы она отвечала твоим стилем — и подключаем её к своему личному аккаунту через Telegram Business.

Всё крутится локально на домашней видеокарте: 8 ГБ VRAM хватает. Никакие переписки никуда не отправляются.

Видео, где это всё собирается: [часть 1](https://youtu.be/j1nruUFyuTo) · [часть 2](https://youtu.be/xKmh-WXrnps?si=BKI6wy08cVIoaIHP).

---

## ⚠️ Прочитай, прежде чем начинать

**Это эксперимент, а не инструмент для обмана.** Когда бот отвечает за тебя, твои собеседники этого не знают — они думают, что говорят с человеком. Держи в голове:

- **Рассказывай людям.** Одно дело — розыгрыш с друзьями, которым ты потом всё объяснишь, другое — систематически обманывать близких.
- **Не подключай к чатам, где решаются реальные вопросы:** деньги, работа, здоровье, договорённости. Модель уверенно выдумывает факты.
- **Переписка — это данные двух людей**, не только твои. Не выкладывай датасет, досье и логи никуда. В `.gitignore` уже прописано всё, что нельзя коммитить, — не ослабляй его.
- **Не выдавай себя за другого человека.** Обучай на своих переписках и запускай от своего имени.

Скрипт `sanitize_jsonl.py` маскирует пароли, телефоны, почты, токены и номера счетов — но это регулярки, а не магия. Пароль, отправленный отдельным сообщением без слова «пароль», он не поймает.

## Как это работает

```
result.json (экспорт Telegram)
      │
      ├─ build_dataset.py ──► dataset.jsonl ──► sanitize_jsonl.py ──► split_dataset.py
      │                                                                    │
      │                                                     train_v2.jsonl / val_v2.jsonl
      │                                                                    │
      │                                                              train.sh (QLoRA)
      │                                                                    │
      │                                                               lora_v2/  ◄─ твой стиль
      │                                                                    │
      ├─ stats_timing.py   ──► timing_profile.json ──┐          serve_model.py (:8008)
      ├─ stats_stickers.py ──► stickers_top.json ────┤                      │
      └─ facts_extract.py  ──► facts/<id>.txt ───────┴──────────────► bot_v2.py
                                                                            │
                                                             Telegram Business → твой аккаунт
```

Две части, которые важно не путать:

- **LoRA даёт стиль.** Модель учится писать твоими словами, твоей пунктуацией, твоей длиной сообщений. Но она не знает фактов о твоей жизни.
- **Досье и заметки дают память.** `facts/<id>.txt` (кто это, как вы общаетесь) и `me_now.txt` (что у тебя сейчас происходит) подставляются в системный промпт перед каждым ответом.

Без второй части модель уверенно сочиняет: «еду к бабушке», «завтра в школу».

## Шаг 1. Экспорт переписок

В **Telegram Desktop** (не в телефоне): Настройки → Продвинутые настройки → Экспорт данных из Telegram.

Отметь:
- **Только личные чаты** — группы и каналы в датасете только мешают
- **Стикеры**, если хочешь, чтобы бот отвечал твоими стикерами
- Формат — **JSON** (не HTML!)
- Период — весь

Выгрузка может занять несколько часов: Telegram отдаёт данные порциями. На выходе — папка с `result.json` (у меня 119 МБ на 250 тысяч сообщений) и подпапкой `chats/` с медиа.

Положи `result.json` и `chats/` в корень проекта.

## Шаг 3. Сборка датасета

```bash
python build_dataset.py                                          # → dataset.jsonl
python sanitize_jsonl.py --in dataset.jsonl --out dataset_sanitized.jsonl
python split_dataset.py                                          # → train_v2.jsonl / val_v2.jsonl
```

Дальше — два скрипта, которые делают поведение бота живым:

```bash
python stats_timing.py     # → timing_profile.json  (как быстро ты отвечаешь в каждый час)
python stats_stickers.py   # → stickers_top.json    (твои любимые стикеры)
```

**Как устроен обучающий пример** (одна строка `train_v2.jsonl`) — подробнее в [`dataset_schema.jsonc`](dataset_schema.jsonc):

```json
{
  "contact": "Друг",
  "messages": [
    { "role": "system",    "content": "Ты — Максим. Ты переписываешься в Telegram с человеком по имени Друг..." },
    { "role": "user",      "content": "[фото]\nсмотри какой сетап собрал" },
    { "role": "assistant", "content": "ооо\nкрасиво" },
    { "role": "user",      "content": "го завтра в дотку?" },
    { "role": "assistant", "content": "давай\nтолько после 7" }
  ]
}
```

Ключевые решения, до которых я дошёл не сразу:

1. **Окна до 10 реплик**, а не пары «вопрос-ответ» — модель видит контекст разговора.
2. **Твои сообщения подряд склеиваются через `\n`** в один ход. Бот потом разошлёт их отдельными сообщениями — как ты и пишешь в жизни.
3. **Имя собеседника в системном промпте** — маме и друзьям пишут по-разному, и модель это выучивает.
4. **Медиа не выкидываются, а помечаются** `[фото]`, `[голосовое]`, `[стикер 😂]`. Если их просто удалить, твой ответ на мем приклеится к чужой фразе — и модель научится отвечать невпопад (у меня так было в каждом десятом примере).
5. **Сессии режутся по паузам:** больше 4 часов — новый разговор; больше 5 минут внутри твоего монолога — тоже. Иначе все твои сообщения за день склеятся в один гигантский ответ.

Настройки — константы в начале `build_dataset.py` (`MAX_TURNS`, `SESSION_GAP`, `MAX_TURN_MSGS` и т.д.).

## Шаг 4. Обучение

```bash
bash train.sh
```

QLoRA 4-bit поверх `unsloth/Qwen3.5-4B`, одна эпоха, loss считается только на твоих репликах. На RTX 4060 это ~1 час 45 минут на 15 тысячах примеров.

- Чекпоинты каждые 50 шагов в `~/tgstyle/out` — прервал `Ctrl+C`, запустил `train.sh` снова, обучение продолжится с последнего.
- Лучший чекпоинт по `eval_loss` сохранится в `lora_v2/`.
- Следить за процессом: `tail -f train.log` и `watch -n 2 nvidia-smi`.

Ориентир: `eval_loss` должен монотонно падать и выйти на плато (у меня 2.72 → 2.44). Обучается 0,5% весов модели — в этом и смысл LoRA.

## Шаг 6. Подключение к своему аккаунту

Telegram Business — официальная фича Premium: обычно её используют магазины для автоответчиков, а мы подключим к ней свою модель. Аккаунт при этом в безопасности: никаких сторонних сервисов и риска бана.

1. **@BotFather** → `/newbot` → получи токен
2. **@BotFather** → `/mybots` → твой бот → **Bot Settings → Business Mode → Turn on**
3. **Telegram на телефоне** → Настройки → **Telegram для бизнеса** → **Чат-боты** → выбери своего бота
4. Настрой конфиг:

```bash
cp bot_config.example.json bot_config.json   # впиши token
```

Запускай в двух терминалах:

```bash
python serve_model.py    # держит модель в VRAM, отвечает на localhost:8008
python bot_v2.py         # бот: слушает Telegram, применяет поведенческий слой
```

**Whitelist пустой — бот молчит.** Это защита от «случайно ответил всем». Попроси друга написать тебе: в логе появится строка `НЕ в whitelist: id=123456789 (Имя @username)`. Добавь этот id в `bot_config.json` и перезапусти бота:

```json
"whitelist": [123456789],
"names": { "123456789": "Саня" }
```

В `names` пиши имя так, как контакт записан у тебя в Telegram, — именно это имя модель видела при обучении.

## Шаг 7. Память о контактах

```bash
python facts_extract.py 123456789 987654321    # id через пробел
```

Скрипт читает последние 600 сообщений каждого чата, прогоняет через базовую модель и складывает досье в `facts/<id>.txt`:

```
Что ты знаешь о Саня:
- зовёте друг друга «саня» и «димон»
- переехал в другой город, играет в доту по вечерам
- обсуждаете игры и учёбу
```

**Останови `serve_model.py` перед запуском** — видеокарта одна, две модели в 8 ГБ не влезут.

Досье обязательно вычитай руками: модель тащит туда протухшие детали («завтра уезжает на море») и всякий мусор вроде номеров счетов. Это обычный текст — правь свободно, бот перечитывает файл перед каждым ответом, перезапуск не нужен.

Ещё создай `me_now.txt` (шаблон — `me_now.example.txt`) — короткая заметка о том, что у тебя происходит:

```
Сейчас лето, каникулы, учёбы нет.
Ты дома, никуда не уезжал. Спрашивают где ты — дома, за компом.
Если зовут куда-то и спрашивают время — не называй конкретный час, отвечай «мб», «позже отпишу».
```

Держи её в 4–5 строк: длинные инструкции маленькая модель начинает игнорировать. И формулируй фактами («каникулы, учёбы нет»), а не запретами («не говори про школу») — так работает заметно лучше.

## Настройки бота

Всё в `bot_config.json`, применяются после перезапуска `bot_v2.py` (сервер трогать не нужно):

| Параметр | Что делает |
|---|---|
| `whitelist` | id чатов, где бот отвечает. Пустой = молчит везде |
| `names` | как модель называет каждый контакт |
| `temperature` | 0.5 — суше и предсказуемее, 0.7 — живее, но чаще заносит |
| `top_p` | отсекает маловероятные слова: 0.8 консервативно, 0.95 свободнее |
| `delay_scale` | множитель пауз. `1.0` — как отвечаешь ты; `0.2` — ускорить для отладки |
| `night_hours` | часы, когда бот молчит (по умолчанию 5–8 утра) |
| `ignore_prob` | вероятность проигнорировать короткое сообщение, как живой человек |
| `history_max` | сколько сообщений контекста помнить |

**Что делает поведенческий слой** — то, ради чего всё и затевалось:

- копит серию сообщений и отвечает один раз, как человек, который дочитал до конца
- ждёт столько, сколько ждёшь ты в этот час суток (из `timing_profile.json`)
- показывает «печатает…» пропорционально длине сообщения
- разбивает ответ по `\n` на отдельные сообщения
- ночью молчит, иногда игнорит короткие реплики
- отправляет твои настоящие стикеры (из `stickers_top.json`), когда модель решит ответить стикером
- видит, на какое сообщение ответили реплаем, и понимает медиа как `[фото]`, `[голосовое]`
- **если ты сам написал в чат — автоответ отменяется**, чтобы вы не писали хором
- не повторяет то, что уже говорил недавно: перегенерирует, а если снова повтор — молчит

## Грабли

Вещи, на которые я потратил время. Может, сэкономят его тебе.

**Модель отвечает простынями на 15 сообщений.** Твои монологи за день склеились в один ход (у меня рекорд — 458 сообщений в одном примере). Лечится резкой сессий: `BURST_GAP = 300` и `MAX_TURN_MSGS = 6` в `build_dataset.py`.

**Модель пишет рассуждения прямо в чат** («Пользователь спрашивает о… подумаю, что ответить»). Qwen3.5 умеет думать в блоке `<think>`, и шаблон по умолчанию этот блок открывает. Нужен `enable_thinking=False` при генерации. И обязательно вырезай **незакрытые** блоки: если размышление упрётся в лимит токенов, тег не закроется, мусор попадёт в историю диалога и сломает все следующие ответы.

**Ответы невпопад.** Скорее всего, ты выкинул медиа из датасета — и модель училась отвечать на сообщения, которых не видит. Плейсхолдеры `[фото]`/`[стикер]` решают.

**Модель отвечает и за собеседника.** В `generate` нужен явный `eos_token_id` токена `<|im_end|>`.

**Ошибки токенизатора у Qwen3.5.** Модель мультимодальная, поэтому шаблон надо рендерить в строку (`tokenize=False`) и токенизировать через `tokenizer.tokenizer`.

**Бот шлёт одно и то же сообщение подряд.** Модель залипла в петле внутри одной генерации — в `bot_v2.py` дубли схлопываются, а повтор недавнего ответа перегенерируется.

**В датасет утекли номера счетов.** Регулярки телефонов не ловят IBAN — он начинается с букв. Добавлено, но перед публикацией любых артефактов проверяй сам:
```bash
grep -oE "\b[A-Z]{2}[0-9]{2}[A-Z0-9]{11,30}\b" train_v2.jsonl | head
```

**Обучение и `facts_extract.py` дерутся за видеокарту.** 8 ГБ хватает ровно на одну модель — запускай по очереди.

## FAQ

**Можно без Premium?** Для Telegram Business — нет. Но можно поднять обычного бота: модель и сервер те же, меняется только способ доставки сообщений.

**Другая модель?** Меняй `MODEL_NAME` в `train_v2.py`. Меньше 4B — стиль ловится хуже; больше — не влезет в 8 ГБ.

**Сколько нужно сообщений?** У меня 15 тысяч примеров из 250 тысяч сообщений. Тысяч от пяти примеров стиль уже прощупывается.

**Модель врёт про факты.** Так и будет: LoRA учит стиль, а не биографию. Правь `facts/` и `me_now.txt` — это единственный источник фактов для модели.

**Мало VRAM.** Уменьши `MAX_SEQ_LEN` до 512 в `train_v2.py`.
